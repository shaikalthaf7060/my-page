# Shaik Althaf — Interactive 3D Developer Portfolio

A dynamic, high-performance personal portfolio built with React, Three.js, and GSAP. Features an interactive 3D character with real-time pointer tracking, custom lighting, fluid scroll-driven animations, and an interactive 3D tech stack simulation.

**Live Demo**: [althu.vercel.app](https://althu.vercel.app)  
**Author**: [Shaik Althaf](https://linkedin.com/in/shaik-althaf)

---

## Features

- **Interactive 3D Avatar**: Real-time cursor and head articulation, dynamic specular highlights, custom tone mapping, and responsive camera framing powered by Three.js.
- **Scroll-Driven Storytelling**: Seamless multi-stage timelines built with GSAP and ScrollTrigger, transitioning through About, Experience, Work, and Tech Stack.
- **Interactive 3D Tech Stack**: Physical sphere simulations with dynamic pointer repulsion, momentum flicking, and soft-body boundary containment.
- **Project Showcase**: Sleek project showcase highlighting full-stack architectures, AI applications, and research publications.
- **Responsive HUD Design**: Adaptive layout engineered for desktop, tablet, and mobile displays with custom differences-blend cursor effects.

---

## Built With

- **Frontend**: React 18, Vite, HTML5, Modern CSS
- **3D Graphics & Physics**: Three.js, WebGL, ACESFilmic Tone Mapping, RGBELoader
- **Animations**: GSAP (GreenSock), ScrollTrigger
- **Typography**: Geist Font Family

## Getting Started

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/shaikalthaf7060/my-page.git
   cd my-page
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
